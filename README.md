
# Soil Moisture Monitoring System using ESP32

## Project Description
This is an IoT-based Soil Moisture Monitoring System using ESP32. It measures the moisture level of soil and helps in automatic plant watering.

## Objectives
- Monitor soil moisture.
- Reduce water wastage.
- Automate the irrigation process.
- Make smart farming easier.

## Components Required
1. ESP32 Development Board
2. Soil Moisture Sensor
3. Soil Moisture Sensor Module
4. Relay Module
5. Mini DC Water Pump
6. Jumper Wires
7. Breadboard
8. Battery / Power Supply
9. USB Cable

## Working Principle
The soil moisture sensor detects the water level in the soil. ESP32 reads the sensor data and processes it. When the soil becomes dry, the system can activate a water pump through a relay.
